# AIMP SMTC Plugin

**AIMP SMTC Plugin** — это плагин для аудиоплеера AIMP, который интегрирует его с системным медиаплеером Windows (System Media Transport Controls, SMTC). Благодаря этому плагину AIMP становится «родным» для Windows: вы можете управлять воспроизведением через всплывающее окно медиа, экран блокировки и системные мультимедийные клавиши.

## Что делает плагин

- **Отображает текущий трек в Windows.** Название композиции, исполнитель и альбом появляются во встроенном медиаплеере Windows (при нажатии клавиш громкости, в центре уведомлений, на экране блокировки).
- **Управление из Windows.** Кнопки «Play», «Pause», «Next» (следующий трек) и «Previous» (предыдущий трек) в системном медиаплеере управляют воспроизведением в AIMP.
- **Синхронизация позиции.** Плагин передаёт в Windows текущую позицию и длительность трека, благодаря чему системный ползунок (прогресс-бар) работает корректно.
- **Перемотка из системы.** Вы можете перетащить ползунок в медиаплеере Windows, и AIMP перемотает трек на нужное время.
- **Автоматическое восстановление.** Плагин самостоятельно подхватывает текущий трек при запуске AIMP и пересоздаёт интеграцию, если плеер был перезапущен.

## Что требуется для сборки

Для компиляции плагина необходимы:

1. **AIMP SDK версии 6.00 (build 3100)**
   - Заголовочные файлы (`apiPlugin.h`, `apiCore.h`, `apiMessages.h`, `apiPlayer.h`, `apiFileManager.h`, `apiObjects.h` и др.) должны лежать в папке `include/` проекта.
   - Скачать официальный SDK можно с сайта [aimp.ru](https://www.aimp.ru/) (раздел «Для разработчиков»).

2. **vcpkg (менеджер пакетов C++)**
   - Необходим для установки пакета `cppwinrt` (C++/WinRT).
   - Убедитесь, что vcpkg интегрирован в систему или проект настроен на его использование (`vcpkg install cppwinrt`).
   - Путь к заголовкам vcpkg должен быть подключён в CMakeLists.txt (обычно `...\vcpkg\installed\x64-windows\include`).

3. **CMake (версия 3.20 или выше)** и компилятор MSVC (Visual Studio 2019/2022 с поддержкой C++17).

## Инструкция по сборке

1. Склонируйте репозиторий.
2. Убедитесь, что AIMP SDK находится в папке `include/`.
3. Настройте CMake через CLion или вручную:
   ```bash
   cmake -B build -DCMAKE_TOOLCHAIN_FILE=[путь_к_vcpkg]/scripts/buildsystems/vcpkg.cmake
   cmake --build build --config Release
4. Зайдите в плагины AIMP, нажмите «Установить» и выберите собранный файл .dll.
